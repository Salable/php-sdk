# Salable PHP SDK

The official PHP SDK for the [Salable](https://salable.app) API. It wraps the REST API for products, plans, subscriptions, and the rest of the Salable resources.

Requires **PHP 8.2+**. The current release is a beta. Install that prerelease with Composer:

```bash
composer require salable/sdk:^1.0@beta
```

`v1.0.0-beta` can still change as the OpenAPI description settles. Composer will not install it for a project that asks for a stable release. `v1.0.0`, published from `main`, is the compatibility promise.

Resource methods are generated by [Kiota](https://github.com/microsoft/kiota) and return promises. Call `wait()` to get the result, the same way the Microsoft Graph PHP SDK does.

## Getting Started

### Installation

```bash
composer require salable/sdk:^1.0@beta
```

That constraint opts in to `v1.0.0-beta` and will follow the stable `v1.0.0` line once it exists. `composer require salable/sdk` stays on stable releases only, so it will not install this beta.

The first time this package is published, register `Salable/php-sdk` on Packagist and enable its GitHub webhook. After that, release tags become `salable/sdk` versions automatically. See [CONTRIBUTING.md](CONTRIBUTING.md).

### Initialisation

Create one `Salable` client with your secret API key and reuse it. The default client calls `https://salable.app`, times out after 30 seconds, retries 429, 503, and 504, and sends a `salable-php/<version>` User-Agent.

```php
<?php

use Salable\Salable;

$salable = new Salable('your-api-key');
```

Your API key is sent as a `Bearer` token on every request. Keep it out of source control.

Use named arguments when you need another origin or your own Guzzle client. A client passed as `httpClient` replaces the default timeout, retries, and User-Agent, so set those on that client if you still want them.

```php
use GuzzleHttp\Client;
use Salable\Salable;

$salable = new Salable(
    apiKey: 'your-api-key',
    baseUrl: 'https://salable.app',
    httpClient: new Client(['timeout' => 10]),
);
```

## CRUD Pattern

Every resource uses the same request-builder pattern. Call `wait()` on the promise each method returns.

| Operation | Method | Example |
|-----------|--------|---------|
| List all  | `->get()->wait()` | `$salable->api->products()->get()->wait()` |
| Get one   | `->byId($id)->get()->wait()` | `$salable->api->products()->byId($id)->get()->wait()` |
| Create    | `->post($body)->wait()` | `$salable->api->products()->post($body)->wait()` |
| Update    | `->byId($id)->put($body)->wait()` | `$salable->api->products()->byId($id)->put($body)->wait()` |
| Delete    | `->byId($id)->delete()->wait()` | `$salable->api->products()->byId($id)->delete()->wait()` |

Product import is `$salable->api->products()->import()`. The HTTP path remains `/api/products/import`.

Create example:

```php
use Salable\SDK\Models\CreateProductRequestSchema;

$body = new CreateProductRequestSchema();
$body->setName('My Product');
$body->setIsActive(true);

$product = $salable->api->products()->post($body)->wait();
```

See [`examples/list_products.php`](examples/list_products.php) for a runnable sample. Set `SALABLE_API_KEY` before running it.

## Error Handling

Non-2xx responses throw `Salable\SDK\Models\ErrorResponseBody`, which extends Kiota's `ApiException`. `getResponseStatusCode()` is the HTTP status.

```php
use Salable\SDK\Models\ErrorResponseBody;

try {
    $product = $salable->api->products()->byId('product-id')->get()->wait();
} catch (ErrorResponseBody $error) {
    error_log(sprintf(
        'API error %s: %s',
        (string) $error->getResponseStatusCode(),
        (string) $error->getTitle(),
    ));
}
```

| Status | Meaning |
|--------|---------|
| `400` | Bad request — check your request body |
| `401` | Unauthorised — check your API key |
| `403` | Forbidden — insufficient permissions |
| `404` | Resource not found |
| `429` | Rate limit exceeded. The default client retries this status. |
| `500` | Internal server error |

## Query Parameters

Query parameters use Kiota's request configuration. `limit` is an `int`. `includeArchived` is a `bool`.

```php
use Salable\SDK\Api\Products\ProductsRequestBuilderGetQueryParameters;
use Salable\SDK\Api\Products\ProductsRequestBuilderGetRequestConfiguration;

$products = $salable->api->products()->get(
    new ProductsRequestBuilderGetRequestConfiguration(
        queryParameters: new ProductsRequestBuilderGetQueryParameters(
            limit: 20,
            after: 'cursor-from-previous-page',
        ),
    ),
)->wait();
```

## Pagination

List responses include `nextCursor` and `previousCursor`. Pass the previous page's `nextCursor` as `after` to read the next page. Pass `previousCursor` as `before` to read the previous page.

```php
use Salable\SDK\Api\Products\ProductsRequestBuilderGetQueryParameters;
use Salable\SDK\Api\Products\ProductsRequestBuilderGetRequestConfiguration;
use Salable\SDK\Models\GetProductListSchema;

$page = $salable->api->products()->get()->wait();
if ($page instanceof GetProductListSchema && $page->getNextCursor() !== null) {
    $next = $salable->api->products()->get(
        new ProductsRequestBuilderGetRequestConfiguration(
            queryParameters: new ProductsRequestBuilderGetQueryParameters(
                after: $page->getNextCursor(),
            ),
        ),
    )->wait();
}
```
